## 先把路线定死

你这个需求里，**真正能在 ComfyUI 里稳定做出来的主 workflow**，我建议用：

**`Inpaint 工作流 + IPAdapter FaceID + Mask Editor`**

而不是直接拿 Kontext 当唯一主干。原因很简单：ComfyUI 官方现在给的 **FLUX.1 Kontext** 教程，是“图片 + 英文提示词”的编辑工作流；官方把 **Mask Editor / Inpainting / Flux Fill dev** 单独作为另一条路线来讲。与此同时，IPAdapter FaceID 文档里明确列出的 FaceID 模型和配套 LoRA，是 **SD15 / SDXL** 这两大家族，不是 Flux Kontext 那条线。换句话说，你要的“身份保持 + 局部 mask/inpaint + 可重复”，最容易落地的是 **Inpaint 主工作流**；Kontext 更适合拿来先试提示词、试术后阶段描述。 [$GitHub$](https://docs.comfy.org/tutorials/flux/flux-1-kontext-dev "https://docs.comfy.org/tutorials/flux/flux-1-kontext-dev")

## 你最终要搭的，是这条主 workflow

节点主线是：

`Load Checkpoint`  
→ `IPAdapter Unified Loader FaceID`  
→ `IPAdapter FaceID` 或 `IPAdapter Advanced`  
→ `KSampler`  
→ `VAE Decode`  
→ `Save Image`

同时还有两条支线：

-   **原图 + mask 支线**：`Load Image` → `MaskEditor` → `VAE Encode (for Inpainting)`
    
-   **身份参考支线**：`Load Image(参考脸图)` → `IPAdapter FaceID / Advanced`
    

官方 Inpainting 文档明确用 `VAE Encoder (for Inpainting)` 这条思路，Mask Editor 也是从 `Load Image` 节点右键打开。 [$ComfyUI Documentation$](https://docs.comfy.org/tutorials/basic/inpaint "https://docs.comfy.org/tutorials/basic/inpaint")

## 先准备模型和依赖

先按 **SD15 家族** 跑通，这是最容易一次成功的版本。你需要：

-   一个 inpaint checkpoint，官方基础教程用的是 `512-inpainting-ema.safetensors`，放到 `ComfyUI/models/checkpoints/`。
    
-   IPAdapter FaceID 的模型和 LoRA。README 列了 SD15 版，例如 `ip-adapter-faceid_sd15.bin`、`ip-adapter-faceid-plusv2_sd15.bin`，以及它们对应的 LoRA 文件，放到 `ComfyUI/models/ipadapter/` 和 `ComfyUI/models/loras/`。 [$GitHub$](https://github.com/cubiq/ComfyUI_IPAdapter_plus "https://github.com/cubiq/ComfyUI_IPAdapter_plus")
    
-   一个 CLIP Vision 模型，README 列了 `CLIP-ViT-H-14-laion2B-s32B-b79K.safetensors` 或更大的 bigG 版本，放到 `ComfyUI/models/clip_vision/`。
    
-   `insightface`。IPAdapter FaceID 文档明确写了 FaceID 模型需要它。
    

你已经装了 `ComfyUI_IPAdapter_plus`，所以缺的是**模型文件**和 `insightface` 运行依赖，不是节点插件本身。

## 模型我建议你这样选

为了少踩坑，直接选这组：

-   checkpoint：`512-inpainting-ema.safetensors`
    
-   ipadapter：`ip-adapter-faceid-plusv2_sd15.bin`
    
-   lora：`ip-adapter-faceid-plusv2_sd15_lora.safetensors`
    
-   clip vision：`CLIP-ViT-H-14-laion2B-s32B-b79K.safetensors`
    

这样整套都是 **SD15 一家**，最不容易“家族混用”。

## 在 ComfyUI 里一步一步搭

## 第 1 组：底模和采样主线

放这些节点：

-   `Load Checkpoint`
    
-   `CLIP Text Encode`（正向）
    
-   `CLIP Text Encode`（负向）
    
-   `KSampler`
    
-   `VAE Decode`
    
-   `Save Image`
    

连接：

-   `Load Checkpoint.MODEL` → 先不要直接进 `KSampler`，先进后面的 FaceID 支线
    
-   `Load Checkpoint.CLIP` → 两个 `CLIP Text Encode`
    
-   `Load Checkpoint.VAE` → `VAE Encode (for Inpainting).vae`
    
-   `Load Checkpoint.VAE` → `VAE Decode.vae`
    

## 第 2 组：原图 + mask + inpaint latent

再放：

-   `Load Image`
    
-   `VAE Encode (for Inpainting)`
    

做法：

1.  在 `Load Image` 上传你的原始人脸照片。
    
2.  右键这个 `Load Image` 节点，选 **Open in MaskEditor**。
    
3.  只涂这几个区域：
    
    -   下眼睑眼袋区
        
    -   泪沟到上颧区过渡
        
    -   需要微调的脸颊交界区
        

不要把鼻子、嘴、眉毛、整张脸都圈进去。

连接：

-   `Load Image.IMAGE` → `VAE Encode (for Inpainting).pixels`
    
-   `Load Image.MASK` → `VAE Encode (for Inpainting).mask`
    

官方文档就是这样：在 `Load Image` 上开 Mask Editor，然后把 mask 用在 inpainting 工作流里。

## 第 3 组：身份保持支线

再放：

-   `IPAdapter Unified Loader FaceID`
    
-   `Load Image`（第二个，专门放身份参考图）
    
-   `IPAdapter FaceID` **或** `IPAdapter Advanced`
    

最省事的搭法：

1.  第二个 `Load Image` 放 **同一个人的正脸清晰照片**。  
    最好是：
    
    -   光线均匀
        
    -   五官无遮挡
        
    -   眼周清楚
        
    -   尽量接近证件照/门诊标准照
        
2.  `Load Checkpoint.MODEL` → `IPAdapter Unified Loader FaceID.model`
    
3.  `IPAdapter Unified Loader FaceID` 里选你下载的 FaceID preset。  
    这个 loader 的作用就是把 FaceID 所需模型整合起来，而且 README 明确说：**如果命名对了，它会自动带上匹配的 FaceID LoRA**。
    
4.  连接：
    
    -   `IPAdapter Unified Loader FaceID.MODEL` → `IPAdapter FaceID.MODEL` 或 `IPAdapter Advanced.MODEL`
        
    -   `IPAdapter Unified Loader FaceID.IPADAPTER` → `IPAdapter FaceID.IPADAPTER` 或 `IPAdapter Advanced.IPADAPTER`
        
    -   `参考图 Load Image.IMAGE` → `IPAdapter FaceID.image` 或 `IPAdapter Advanced.image`
        

如果你用的是 `IPAdapter Advanced`，它文档里有个非常关键的口子：**`attn_mask`**。这个 mask 会限制 IPAdapter 对最终图像的影响范围，白色区域影响最大，黑色区域不受影响。对你这种“只想让身份约束集中在眼周和面中”很有用。 [$GitHub$](https://github.com/cubiq/ComfyUI_IPAdapter_plus/blob/main/NODES.md "https://github.com/cubiq/ComfyUI_IPAdapter_plus/blob/main/NODES.md")

所以你可以把刚才那张 mask 再接给：

-   `Load Image.MASK` → `IPAdapter Advanced.attn_mask`
    

这样 FaceID 的“像本人”约束，也更集中在你关心的区域，而不是把整张脸都硬锁死。

## 第 4 组：采样收口

连接：

-   `IPAdapter FaceID / Advanced` 的 `MODEL` 输出 → `KSampler.MODEL`
    
-   `CLIP Text Encode(正向)` → `KSampler.positive`
    
-   `CLIP Text Encode(负向)` → `KSampler.negative`
    
-   `VAE Encode (for Inpainting)` 的 `LATENT` → `KSampler.latent_image`
    
-   `KSampler.SAMPLES` → `VAE Decode.samples`
    
-   `VAE Decode.IMAGE` → `Save Image.images`
    

到这里，主工作流就成了。

## 参数先这样填

## IPAdapter

IPAdapter 文档给的 `weight` 默认建议起点就是 **0.8**。对你的场景，我建议先这样：

-   `weight = 0.65 ~ 0.8`
    
-   `start_at = 0`
    
-   `end_at = 0.65 ~ 0.8`
    
-   `weight_type = linear`
    

官方文档里写了：`weight` 的一个好起点是 `0.8`，`start_at / end_at` 控制它在采样哪个阶段生效。

## KSampler

这部分我给你的是实操建议，不是死规定：

-   `steps = 22 ~ 30`
    
-   `cfg = 4.5 ~ 6.5`
    
-   `denoise = 0.18 ~ 0.32`
    

经验上：

-   **术后即刻版**：`denoise` 稍高一点，比如 `0.24 ~ 0.32`
    
-   **10–30 天恢复版**：`denoise` 稍低一点，比如 `0.18 ~ 0.24`
    

因为恢复版通常只需要更自然、更轻微的改动。

## 为什么这套比“直接上 Kontext”更适合你

因为官方 Kontext 工作流本身强调的是：

-   `Load Diffusion Model`
    
-   `DualCLIP Load`
    
-   `Load VAE`
    
-   `Load Image(from output)`
    
-   `CLIP Text Encode`
    

它确实很适合图片编辑和角色一致性保持，但官方这套教程本身不是在讲 mask/inpaint；Mask Editor 和 inpainting 是另一组教程和节点。你这个术后 mockup 属于**必须局部改、必须保身份、必须可控**，所以最终落地还是 inpaint 主线更稳。

## 但你仍然可以把 Kontext 用起来

我建议你把 **Kontext 当“提示词预演器”**。

单独再做一个小 workflow：

-   `Load Diffusion Model`：`flux1-dev-kontext_fp8_scaled.safetensors`
    
-   `DualCLIP Load`：`clip_l.safetensors` + `t5xxl_fp16.safetensors` 或 `t5xxl_fp8_e4m3fn_scaled.safetensors`
    
-   `Load VAE`：`ae.safetensors`
    
-   `Load Image(from output)`
    
-   `CLIP Text Encode`
    

这是 ComfyUI 官方 Kontext Dev 教程列出来的本地模型组合，而且官方还特别写了：**prompt 只支持英文**。

你可以先在 Kontext 里把两种“语义方向”试出来：

-   术后即刻：轻微红、轻微肿、去眼袋但不夸张
    
-   恢复期：红退掉、肿消失、下睑更平顺自然
    

把你觉得最贴近的 prompt 再复制回上面的 inpaint 主 workflow。

## ControlNet 要不要加

先别加。

你现在这条主 workflow 已经是：

-   原图 inpaint
    
-   局部 mask
    
-   身份保持
    

这本身就已经非常强地锁住了姿态、构图和五官位置。  
ControlNet 只有在这几种情况才值得加：

-   你发现眼睛形状老跑
    
-   头部轮廓被改
    
-   表情被带偏
    

而且你当前 `models/controlnet` 还是空的，占位文件状态，说明你还没有实际的 ControlNet 模型文件。没有模型，`comfyui_controlnet_aux` 只有预处理器，不会真正起控制作用。

## 你要记住的两个关键点

第一，**mask 一定要小**。  
你圈得越大，模型越容易“顺手整容整张脸”。

第二，**身份参考图一定要干净**。  
IPAdapter / FaceID / PuLID 这类方法，参考图质量差，结果就更容易“像别人”。
